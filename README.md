# 2shabby.github.io

Personal site for Shahbaz Shaik. It uses the Jekyll version supported by GitHub Pages and deploys directly from the `main` branch without a custom build workflow.

## Edit

- Update the landing-page copy and selected work in `index.md`.
- Update identity, metadata, and external links in `_config.yml`.
- Add writing under `_posts/` using Jekyll's `YYYY-MM-DD-title.md` convention.

## Preview

With Ruby 3 and Bundler installed:

```sh
bundle install
bundle exec jekyll serve
```

The site is available locally at `http://127.0.0.1:4000`.
